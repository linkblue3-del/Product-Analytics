# Sample Sales Data

## Overview

1000 rows of synthetic e-commerce sales data for workshop exercises.

## File

**sample_sales.csv** - Product sales transactions

## Schema

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| order_id | int | Unique order ID | 1001 |
| product_id | string | Product identifier | P042 |
| product_name | string | Product name | Laptop |
| category | string | Product category | Electronics |
| quantity | int | Items purchased | 2 |
| price | float | Unit price ($) | 899.99 |
| order_date | string | Purchase date | 2024-01-15 |
| customer_id | string | Customer ID | C123 |
| region | string | Geographic region | West |

## Categories

- Electronics (laptops, phones, tablets)
- Clothing (shirts, pants, shoes)
- Home (furniture, kitchen, decor)
- Books (fiction, non-fiction, educational)
- Sports (equipment, apparel, accessories)

## Regions

- North, South, East, West

## Notes

- All data is synthetic for educational purposes
- Prices range from $9.99 to $1,999.99
- Dates span 2024-01-01 to 2024-12-31
